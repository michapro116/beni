# BENICONFORT — Sitio web comercial

Sitio estático responsive en HTML, CSS y JavaScript, sin dependencias de compilación ni backend.

## Ejecutar localmente

Abrir `index.html` en un navegador. Para servirlo localmente desde esta carpeta:

```bash
python3 -m http.server 8000
```

Luego visitar `http://localhost:8000`.

## Publicar

Subir el contenido completo de esta carpeta a cualquier hosting estático compatible (por ejemplo, Netlify, Cloudflare Pages, GitHub Pages o un hosting tradicional). No requiere variables de entorno.

## Archivos

- `index.html`: estructura, contenido, metadatos SEO y datos estructurados.
- `styles.css`: identidad visual, componentes y responsive.
- `script.js`: menú móvil, acordeón FAQ y año dinámico.
- `assets/`: ilustraciones SVG conceptuales y favicon.
